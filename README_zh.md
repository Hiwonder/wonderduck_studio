# WonderDuck Studio

[English](README.md) | 简体中文

Studio 是 WonderDuck 的网页控制台，提供运动控制、设备状态、动作编辑、校准和模型管理。机器人启动后，在浏览器访问 `http://设备IP:8090`。

设备的更新与部署方法见 WonderDuck 主仓库的 README：[GitHub](https://github.com/Hiwonder/wonderduck) | [Gitee](https://gitee.com/hiwonder_official/wonderduck)。请在可信的局域网中使用控制台。
