# WonderDuck Studio

English | [简体中文](README_zh.md)

WonderDuck Studio is the robot's web console for motion control, device status, action editing, calibration, and model management. Once the robot has started, open `http://DEVICE_IP:8090` in a browser.

For update and deployment instructions, see the WonderDuck README on [GitHub](https://github.com/Hiwonder/wonderduck) or [Gitee](https://gitee.com/hiwonder_official/wonderduck). Use the console on a trusted local network.
